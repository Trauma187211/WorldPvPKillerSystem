# World PvP Killer System

A lightweight World of Warcraft addon that tracks world‑PvP kill streaks and assigns escalating killer titles based on player performance. As players rack up kills, the addon announces their streaks and issues zone‑wide warnings when dangerous killers emerge.

## 🔥 Features
- Real‑time PvP kill detection  
- Kill streak tracking per player  
- Escalating killer titles:
  - Murderer (1–2 kills)
  - Serial Killer (3–5 kills)
  - Mass Murderer (6–9 kills)
  - Slaughterer (10–14 kills)
  - Executioner (15–19 kills)
  - Death Dealer (20–29 kills)
  - Grim Reaper (30+ kills)
- Zone warnings when killers reach new tiers  
- Fully resets each session (no SavedVariables)

## 🎮 Why Use It?
Adds atmosphere, tension, and personality to world‑PvP encounters. Whether you're hunting killers or becoming one, the addon makes every kill feel impactful.

## 📦 Installation
1. Download the addon folder.  
2. Place it in:  
   `World of Warcraft/_classic_/Interface/AddOns/`  
3. Restart or reload your UI.
